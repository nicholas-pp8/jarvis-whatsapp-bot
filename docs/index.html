JARVIS

Your own WhatsApp bot. Free hosting. Pairing code, no QR.

Your data stays with you. This page runs only in your browser. Nothing you type here is sent anywhere, and your WhatsApp login (session) is created on your own host, never on this site.

1. What you need

  • A WhatsApp number for the bot (a spare number is best, see the ban-risk note below)
  • A free host that runs Node.js 20+ (see step 4)
  • About 150 MB of RAM and 700 MB of disk

2. Make your settings file

Fill this in and copy the result. It becomes your .env file.






Never post your .env or API keys in a chat, issue or screenshot.



3. Get the code


git clone https://github.com/nicholas-pp8/jarvis-whatsapp-bot.git
cd jarvis-whatsapp-bot
npm install


Put your .env file in that folder. No git on your host? Use the ZIP download.

5. Start and pair (no QR)


  1. Run npm start.
    2. 

  2. The bot shows an 8-character pairing code in the console.
    3. 

  3. On the bot phone: WhatsApp, Linked devices, Link a device, then Link with phone number instead.
    4. 

  4. Type the code. Wait a few seconds. The bot says it is online.
    5. 

  5. Send /menu to the bot to see all 39 commands.


The login is saved in the auth/ folder on your host. Keep that folder private and never upload it anywhere.



6. Ban-risk notes


    

  • WhatsApp can ban numbers that act like bots. Use a spare number, not your main one.
    • 

  • Group tools (/tagall, bulk add or remove, auto moderation) are the riskiest. They are off by default and rate limited.
    • 

  • Do not add the bot to hundreds of groups or spam messages.
    • 

  • This is an unofficial project. Use it at your own risk.
